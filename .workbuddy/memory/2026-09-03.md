## 构建环境踩坑（本机 Windows + Git Bash）

- `pnpm` 在 Git Bash 下 shim 路径错乱（`Cannot find module 'F:\c\Users\...'`）→ 用 node 直跑 pnpm.mjs：`node "C:/Users/OrBit-0297/AppData/Local/pnpm/global/v11/.../pnpm.mjs" add ...`。
- `cargo check` 链接失败：GNU `link` 遮蔽 MSVC `link.exe` → 前置 MSVC bin 到 PATH 并导出 `LIB`/`INCLUDE`（详见 MEMORY.md）。
