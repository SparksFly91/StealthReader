# 2026-09-07

## 修复 Windows 11 窗口圆角透明缝隙

- 问题：Win11 下 DWM 给无边框透明窗口默认裁约 8px 系统圆角，与前端 CSS `--radius-window: 12px` 不一致，两段弧线之间露出一圈透明留白。
- 修复：Rust 侧启动时对 main 窗口调用 `DwmSetWindowAttribute(DWMWA_WINDOW_CORNER_PREFERENCE, DWMWCP_DONOTROUND)` 关闭系统圆角，窗口边界完全由 CSS 圆角决定。
- 改动：`src-tauri/src/lib.rs` 新增 `disable_system_rounded_corners()`（cfg windows）并在 setup 中调用；`Cargo.toml` 增加 `[target.'cfg(windows)'.dependencies] windows 0.61.3`（features: Win32_Foundation, Win32_Graphics_Dwm，与 lock 中 tauri 已用版本一致）。
- 验证：`cargo check` 通过（仅余原有的 ReadingProgress 未使用警告）。

## 修复圆角外侧灰色直角残影（二次）

- 现象：关掉系统圆角后，圆角外侧仍有一块与 `--color-window-bg` 同色的方形灰雾/直角残影。
- 根因：透明窗口下 `.container`（MainLayout.vue）的 `backdrop-filter: blur(20px)` 会向后取样但不按 border-radius 裁剪，在圆角外侧糊出矩形灰块；且容器背景本就不透明（`--color-window-bg`），该模糊本身无意义。
- 修复：删除 MainLayout.vue `.container` 的 `backdrop-filter: blur(20px)`；补上 index.html 挂载点 `#app` 为透明背景（原只写了 html/body/#root，而 Vue 实际挂载在 `#app`）。
- 经验：Tauri 2 透明窗口 + CSS border-radius 场景下，全屏容器上不要加 backdrop-filter，会破坏圆角裁剪；挂载点需显式设为透明。

## 修复开启阴影时的直角边框线（三次，最终方案）

- 现象：`setShadow(true)` 时 DWM 原生阴影跟着"方形窗口"走，圆角外侧出现直角边框线/直角影。
- 根因：DWM 阴影只作用于矩形 HWND，永远无法跟随 CSS border-radius；transparent+decorations:false 的窗口不满足 DWM 圆角条件。
- 最终方案（浮窗式，用户选"先跑起来看看"）：
  - 全局彻底关闭 OS 阴影：所有 `appWindow.setShadow(...)` 一律改为 `setShadow(false)`（MainLayout、Home、Reader 的 onMounted/onUnmounted）。
  - 阴影改由 CSS `box-shadow` 呈现（跟随 border-radius），由 `settingStore.appearance.showShadow` / `reader.showShadow` 驱动 class。
  - 内容四周留透明边距 `--window-gap: 12px`（新增于 global.css），让 box-shadow 有落点、并透出桌面。
  - MainLayout 重构：`.window-shell`（透明+padding）包 `.window-card`（圆角+背景+可选阴影）；Reader 同样用 `.reader-shell` 包 `.glass-panel`，宽高从 100vw/100vh 改为 100%。
  - 清理 Home.vue 不再使用的 settingStore；Appearance.vue 移除 getCurrentWindow import 与 setShadow 调用。
- 验证：`vue-tsc --noEmit` 通过（EXIT=0）。`pnpm build` 在 vite 清空 dist 时被环境 safe-delete 护栏拦截（72 文件>50 阈值），非代码问题。
