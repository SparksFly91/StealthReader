# 上班摸鱼阅读神器：一款会"隐身"的小说阅读器

> 献给每一个想在工位上读完小说、又不想被老板发现的你。无账号、无广告、纯本地，窗口还会隐身。

---

## 01 · 摸鱼的痛，只有摸鱼人懂

上班的你，是不是也有这样的时刻——

会议间隙、需求排期前的十分钟、下午四点半那杯咖啡的续航空档……脑子已经飘到昨晚小说里的章节了，可屏幕还停在工作文档上。

你偷偷切到网页看小说，结果：

- 弹窗广告比正文还显眼，一个手滑全公司都看到你在"看福利视频"
- 网页配色花花绿绿，隔着三排工位都能看出你在摸鱼
- 手机藏在桌下看，脖子酸、眼睛累，还容易漏消息
- 更别提那些要登录、要注册、还要联网的阅读平台

> 摸鱼是刚需，但摸鱼也是门技术活。

所以，有位开发者做了一款**专为"安静阅读"而生的桌面小说阅读器**——**幽灵阅读器 · Stealth Reader**。

它安静、轻盈、本地优先，没有账号体系，没有广告位，不采集任何数据。核心只做一件事：**让你在工位上好好读完一本书。**

---

## 02 · 它为什么天生适合摸鱼？

一句话概括：

> **一款会隐身、纯本地、无广告的桌面小说阅读器。**

它用 Tauri 2 + Vue 3 + Rust 打造，支持 Windows / macOS / Linux。安装包小、启动快、不吃内存——轻到你可以随手打开，随时关掉。

"幽灵"二字，是它最核心的产品哲学：**在你需要时出现，在老板经过时彻底隐身。**

而它最离谱的地方，是一整套为"工位阅读"设计的隐形能力。

---

## 03 · 幽灵阅读模式：真正的"摸鱼隐身术"

这是整款产品最有性格的地方，也是摸鱼党的核心装备。

阅读窗口支持 **透明背景 + 圆角毛玻璃外观**，窗口可任意拖拽、**可以置顶显示**，还提供窗口阴影开关。

想象一下这个画面：

窗口悬在屏幕一角，半透明的玻璃质感，文字静静浮在桌面上——底下正是你的工作界面。你一边"看着"工作窗口，一边用眼角余光追着小说剧情。鼠标一动就切回工作，谁也看不出你在读书。

![幽灵阅读模式：透明毛玻璃，悬在桌面上](../images/4.png)

> 幽灵阅读，是这款产品名字最好的注脚，也是摸鱼党最硬的底气。

## 04 · 书架：你的私人图书馆

摸鱼也要有条不紊。书架以封面网格展示所有书籍，支持按书名模糊搜索，右键即可编辑书名 / 作者 / 简介，删除还有二次确认，手滑也不怕。

![书架管理：封面网格，一目了然](../images/1.png)

点击进书后，封面、作者、章节数、总字数、阅读进度一应俱全，简介悬停即看，章节列表分页展示（每页 20 / 50 / 100 可选），还能按章节标题模糊搜索——中午想续读某一章，两秒定位。

## 05 · 分页阅读：像翻书，也像刷手机

- **点击翻页**：点页面左 / 右半屏即可翻页，符合直觉
- **键盘翻页**：`↑↓` / `PgUp` / `PgDn` / 空格 / `←→` 全支持，单手就能翻
- **快速切换章节**：上一章 / 下一章一键跳转，章节边界有提示
- **外观实时生效**：字体大小、字体颜色、背景颜色与透明度、阅读窗口大小，调整立即生效

> 阅读器本身也是"隐形"的：没有工具条遮挡，把空间全部留给文字。

## 06 · 摸鱼的底气，还来自这些细节

### 深色主题 + 阅读设置

**全局深色主题**适配明暗两种模式，跟随系统或手动切换；阅读设置里字体、颜色、背景透明度、窗口大小、阴影开关一应俱全，怎么舒服怎么调。

![阅读设置：字体、颜色、透明度随心调](../images/2.png)

### 智能解析：一次导入，自动分章

从网上下载的 TXT 小说，最怕乱码和章节混乱。它基于 `chardetng` 自动识别 GBK / UTF-8 等编码，打开不再乱码；再用正则智能识别「第 X 章」「Chapter N」「楔子 / 序章 / 前言 / 引子 / 后记 / 尾声 / 番外」等格式，自动拆好章节目录。导入完成还会自动统计**章节数**和**总字数**。

### 阅读进度自动保存

上次读到哪一章、哪一页，下次打开一键续上，摸鱼体验无缝衔接。

## 07 · 技术控视角：它凭什么又快又轻？

- **桌面壳**：Tauri 2 —— 相比 Electron，安装包和内存占用大幅缩减
- **前端**：Vue 3 + TypeScript + Vite + Naive UI，开发体验现代、界面清爽
- **后端**：Rust —— `sqlx` + SQLite 存储、`chardetng` 编码检测、`regex` 智能分章
- **状态管理**：Pinia + 持久化插件，设置跨会话保存
- **工程化**：GitHub Actions 多平台打包，Windows / macOS / Linux 一键出包

Rust 负责最重的解析与存储，Vue 负责最顺滑的界面，各司其职。
