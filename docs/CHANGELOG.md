# 更新日志

本文件记录 StealthReader 各版本的更新内容。

## v0.4.0（2026-09-01）
### 🎉 新版本发布！

### ✨ 新增功能

- **阅读模式右键快捷调色**：阅读页右键任意位置弹出快捷设置菜单，提供字体颜色与背景颜色调节（含透明度与十六进制值显示），实时生效并自动持久化，无需再进入设置页调整。
- **段落首行缩进**：阅读模式正文按段落自动首行缩进两格，更贴合中文阅读习惯。

### 🎨 优化

- **更新弹窗**：重构更新说明区域为内容滚动 + 分段式布局，进度条移入底部操作区，按钮尺寸紧凑化。
- 取消阅读模式鼠标左键点击翻页，翻页统一通过底部按钮与键盘方向键（↑↓ / PageUp / PageDown）操作。
- 替换应用图标资源。

### 🐛 修复

- **窗口圆角跨平台修复**：新增窗口圆角样式变量，主窗口与阅读器容器统一改用 CSS 圆角渲染；修复 Windows 下从阅读模式返回书籍详情页后窗口圆角丢失、关闭窗口阴影后圆角失效，以及 macOS 下窗口圆角不显示的问题；从阅读模式返回时自动恢复主窗口阴影设置。

### 🎉 新版本发布！

### 🚀 工程

- 新增 `tauri-plugin-prevent-default` 插件，区分开发/生产模式拦截默认事件。
- 优化发布流程：release 工作流自动从 CHANGELOG.md 提取当前 tag 对应版本更新日志作为 Release body。

## v0.2.0（2026-08-24 14:00）
### 🎉 新版本发布！

### ✨ 新增功能

- **小说阅读器**：整页窗口可拖动；正文按字符串自动分页（一屏一页），支持点击左/右半屏、键盘方向键翻页；提供「上一章 / 下一章」快速切换。
- **阅读进度追踪**：新增 `reading_progress` 表记录每章阅读状态；章节列表已读章节置灰显示（`is_read`）；记录书籍最后阅读位置与时间。
- **书籍导入与解析**：自动识别文件编码（GBK/UTF-8/Big5 等）并解码，按正则智能解析章节，事务一次性写入书籍与全部章节。
- **章节标题模糊搜索**：详情页支持按章节标题关键字搜索。
- **全局加载状态**：新增 `useLoading` hook 与全局加载遮罩，可自定义加载文字（导入中…/加载中…/删除中…）。
- **书籍管理**：列表右键「编辑 / 删除」，编辑弹窗、删除二次确认，默认封面图 `cover.jpg`。

### 🎨 优化

- 详情页章节列表双列展示、分页组件；简介区域滚动条包裹；返回按钮悬浮化。
- 阅读器默认封面、返回按钮样式与阅读字号优化。
- 数据库模型与表结构对齐（`introduction` 字段、`chapters` 主键、可空 `last_read_time`）。

### 🐛 修复

- 修复 Windows 下 SQLite 路径无法打开数据库的问题。
- 修复重复阅读已读章节时的 `UNIQUE constraint failed`（改为 UPSERT）。
- 修复删除确认无响应、Tauri 命令参数 camelCase 不匹配、`NaiveDateTime` 序列化失败等问题。

### 🚀 工程

- 配置 GitHub Actions 多平台打包与 release 发布流程（Windows/macOS/Linux）。
